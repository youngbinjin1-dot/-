# 노을 아래 세 친구 🌅

치이카와·하치와레·우사기와 이야기를 나누는 **비공식 팬 콘셉트 웹 앱**입니다. 노을 아래 함께 쉬는 그림을 중심으로, 세 친구가 각자의 말풍선과 말투로 답합니다.

## 주요 기능

- **하나의 만화 컷:** 질문할 때마다 기존 컷의 질문과 답변만 바뀝니다.
- **이미지를 가리지 않는 말풍선:** 그림 바깥 좌우에 배치합니다.
- **세 친구의 개성:** 우사기는 “야하 / 하아! / 우나”와 괄호 속 뜻, 하치와레는 다정하고 자연스러운 문장, 치이카와는 짧은 소리와 괄호 속 뜻으로 답합니다.
- **세계관 반영:** 제초, 자격증 시험, 생계와 친구들의 휴식 등 일상 설정을 대화에 반영합니다. 해석이 갈리는 설정을 확정 사실처럼 설명하지 않도록 구성했습니다.
- **Groq 연결:** 사용자가 자신의 API 키를 입력해 세 친구와 대화합니다.
- **단일 HTML:** 배경 이미지와 글꼴을 포함하며 별도 빌드 과정이 필요 없습니다.

## 저장소 상태

현재 저장소에는 이 안내 문서가 있습니다. 앱 실행과 GitHub Pages 배포를 위해서는 제공받은 `index.html` 파일을 저장소 최상위에 업로드해야 합니다.

## 실행 방법

1. `index.html`을 준비합니다.
2. GitHub Pages에 배포한 주소를 엽니다.
3. **연결 설정**에서 본인의 Groq API 키를 입력합니다.
4. 질문을 입력하고 전송 버튼을 누릅니다.

API 키는 [Groq Console](https://console.groq.com/keys)에서 발급할 수 있습니다. 연결 실패 시 화면의 오류 문구를 확인해 주세요.

## GitHub Pages 배포

1. 저장소 최상위에 `index.html`을 업로드합니다.
2. 저장소의 **Settings → Pages**를 엽니다.
3. **Source → Deploy from a branch**를 선택합니다.
4. **main / (root)**를 선택하고 **Save**를 누릅니다.
5. 배포가 완료되면 Pages 설정에 표시되는 주소로 접속합니다.

## API 키와 개인정보

- API 키를 HTML, README, 커밋 또는 GitHub 저장소에 넣지 마세요.
- 이 HTML 버전은 서버 암호화 방식이 아니라 **브라우저에서 Groq로 직접 요청하는 방식**입니다.
- 키는 현재 페이지 메모리에만 유지하며 브라우저 저장소에 저장하지 않습니다.
- 새로고침·탭 닫기 후에는 키를 다시 입력해야 하며, 연결은 1시간 후 만료됩니다.
- 질문과 대화 맥락은 답변 생성을 위해 Groq로 전송됩니다. 개인정보나 민감한 정보는 입력하지 마세요.
- 공용 API 키를 숨겨 여러 사용자에게 제공하려면 별도 백엔드가 필요합니다.

## 참고 사항

- 실제 답변 생성에는 유효한 Groq API 키와 이용 가능한 모델·한도가 필요합니다.
- 브라우저 직접 연결은 Groq의 CORS 정책과 네트워크 환경에 따라 제한될 수 있습니다.
- 질문 한 번에 세 캐릭터의 답변을 위한 요청이 발생합니다.
- 대화는 페이지 메모리에서만 유지되며 새로고침하면 사라집니다.
- 비공식 팬 프로젝트이며 원작 및 권리자의 공식 서비스와 무관합니다. 캐릭터·이미지·글꼴의 권리는 각 권리자에게 있습니다. 공개 배포와 재사용 전 이용 조건을 확인해 주세요.
